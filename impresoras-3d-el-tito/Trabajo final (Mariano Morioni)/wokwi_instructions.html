Componentes del Circuito

ESP32

Controlador principal del sistema

Potenciómetro

Simula sensor de temperatura (150-250°C)

LED Rojo

Indica calentador encendido

LED Azul

Indica ventilador funcionando

LED Verde

Indica motor de impresión activo

LED Amarillo

Indicador de estado del sistema

Cómo Funciona

1. Control de Temperatura

Gira el potenciómetro para simular cambios de temperatura:

  • < 200°C: LED rojo se enciende (calentador)
  • 200-220°C: Temperatura óptima
  • > 220°C: LED azul se enciende (ventilador)

2. Monitoreo Serial

Abre el monitor serial para ver:

  • Temperatura actual en tiempo real
  • Estado de todos los actuadores
  • Conexión WiFi y MQTT

3. Comandos MQTT

El sistema responde a comandos:

  • start: Inicia motor (LED verde)
  • stop: Detiene motor
  • emergency: Parada de emergencia

Vista Previa del Código

// Función principal de control
void controlTemperature() {
  if (temperature < 200) {
    heaterState = true;
    digitalWrite(HEATER_PIN, HIGH);  // LED rojo ON
  } else if (temperature > 220) {
    fanState = true;
    digitalWrite(FAN_PIN, HIGH);     // LED azul ON
  }
}
